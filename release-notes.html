This release updates QuickFolders to reflect recent changes in Thunderbird’s add-on platform planning. A previously announced restriction affecting Experiment APIs on the Release channel has been postponed to a later ESR cycle (currently targeted for 2027). No immediate action is required. QuickFolders continues to work on both Release and ESR versions of Thunderbird where supported. Users who rely on advanced or experimental functionality may prefer the ESR channel for a more stable environment with fewer platform changes. The recommended migration point from Release to ESR is Thunderbird 153, expected in July 2026. Improvements
  • QuickFolders is now compatible with Thunderbird 154.
  • Made width of tab separators adjustable. [issue 686]
  • Improved compatibility with future Thunderbird versions by removing direct access to the QuickFolders add-on object. [issue 680]
  • Converted storage from legacy preferences (about:config) to local storage API. [issue 677] Settings can now be reset to defaults by uninstalling the add-on — back up your settings first using Store Configuration under Backup and Restore.
Bug Fixes
  • Fixed: messages window content area truncated at the top. [issue 673]
  • Fixed: quickMove shortcut to open recent folders menu. [issue 687]
Miscellaneous
  • Simplified WindowListener by removing pre 140 compatibility code.
