Release 6.10 To support QuickFolders, please buy a QuickFolders Pro license here. Or get the new cheaper QuickFolders Standard License. This is the preferred way of funding all the ongoing work and improvements. Read the new comparison chart to see which functions you get depending on your license. You can also donate from here. Improvements
  • New option to always display QuickFolders Options in a tab.
  • quickJump feature - Use [CTRL] key to open folder in a new TB tab. [issue 540]
  • quickJump - Modifier key [Alt] to open folder in new window. [issue 542]
Accessibility Features
  • Support keyboard navigation of the QuickFolders toolbar. [issue 552]
  • Support keyboard navigation / screen readers in QuickFolders settings. [issue 555]
  • Support adding QuickFolders (bookmark folders) using keyboard. [issue 550]
  • New accessibility option: quickJump / quickMove priority for QF bookmarks in results & screen reader support. [issue 548]
  • New accessibility option: Remove 'customize icon' command from folder context. [issue 551]
Bug Fixes
  • Fixed: CTRL+click Tab popup folder opens 2 Thunderbird tabs. [issue 541]
  • Fixed: No cursive tab on new mails if "display unread tabs as bold" is disabled. [issue 539]
  • Fixed: can no longer remove customized icon from tab. [issue 546]
Miscellanei
  • Compatibility with Thunderbird 138.*
  • Using Web Extension API function for opening support websites - Tb 135 created an unwanted alert.
  • Removed inline event handlers which will be deprecated in Thunderbird 136. [issue 543]
  • Thunderbird 136 retires ChromeUtils.import - replace with importESModule. [issue 547]
  • streamlined onboarding / update screens.
