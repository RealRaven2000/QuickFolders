Release 6.12 Upcoming in the next big release: Thunderbird will soon ask you to choose your preferred update path — either the annual ESR track or the faster monthly releases. Learn more about the new release model The ESR version will stay on v140, increasing minor version numbers and including only security fixes and bug patches, which is often preferable for corporate environments. The monthly release cycle will deliver new features and interface updates as they’re developed. Please check whether your current add-ons support this release model. To help with this, you can install the Add-on Compatibility Check. Improvements
  • Made compatible with Thunderbird 141.*
Bug Fixes
  • Fixed: `nsIMsgFolder.prettyName` removed in Thunderbird 141 - a critical issue that broke folder tabs and many key features — caused by Thunderbird changing how folder names are accessed internally. [issue 595]
  • Fixed: Restored quickMove and quickJump after Thunderbird modernized its interface and replaced older search elements. `search-textbox` removed in Thunderbird 141.[issue 596]
  • QuickFolders toolbar not showing in Betterbird due to mailTabs.query not ready.[issue 598]. There is likely a bug in Betterbird affecting the `mailTabs` extension API, which can affect multiple Add-ons.
