Release 6.11.1 Upcoming in the next big release: Thunderbird will soon ask you to choose your preferred update path — either the annual ESR track or the faster monthly releases. Learn more about the new release model The ESR version will stay on v140, increasing minor version numbers and including only security fixes and bug patches, which is often preferable for corporate environments. The monthly release cycle will deliver new features and interface updates as they’re developed. Please check whether your current add-ons support this release model.
